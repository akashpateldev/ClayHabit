# ClayHabit Mobile App

ClayHabit is a React Native / Expo mobile application designed for organized learning and daily habit building. This app allows users to scan and organize course materials, track their daily progress, and stay committed to their learning goals.

## Features

- **Course Scanner**: Automatically detects and organizes course folders from local storage.
- **Progress Tracking**: Tracks video watch time and overall course completion.
- **Daily Goals**: Interactive UI to set and view daily learning milestones.
- **Modern UI**: Dark mode, glassmorphism-inspired design with premium aesthetics.
- **Platform Support**: Works on Android (Native) and Web (Browser).

## Tech Stack

- **Framework**: Expo / React Native
- **Styling**: Vanilla CSS for Web / StyleSheet for Native
- **State Management**: React Context API
- **Navigation**: Expo Router (File-based routing)
- **Animation**: React Native Reanimated
- **Icons**: Expo Vector Icons (Feather)

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/akashpateldev/ClayHabit.git
   cd ClayHabit
   ```

2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

### Running Locally

- **Web Browser**:
  ```bash
  npx expo start --web
  ```

- **Android/iOS**:
  ```bash
  npx expo start
  ```
  Follow the instructions in the terminal to open the app on your device or emulator.
